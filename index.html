Miyorare is an open-source Android reader for manga, comics, and novels, built around one principle: Stability, Speed, and Smoothness.

Hybrid reading

One app experience for supported manga, comic, and novel sources, plus local reading workflows.

Performance first

New features are designed not to slow startup, Reader, navigation, downloads, Explore, or Favourites when they are not in use.

Open source

Development happens publicly on GitHub so releases, source changes, and project discussions remain inspectable.

Google Drive integration

When enabled by the user, Miyorare can use Google authentication and Google Drive permissions for app data and files used by its sync feature. This integration is optional and is only activated after the user chooses to sign in and grants the requested permissions.
