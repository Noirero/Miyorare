Miyorare

Miyorare is an open-source Android application for reading manga, comics, and novels. Its purpose is to provide a stable, fast, and smooth reading experience for supported online sources and local content.

Miyorare includes reading, browsing, search, favourites, downloads, local-library support, and optional synchronization features. Google access is not required for normal reading.

What Miyorare does

Miyorare helps users discover and read supported manga, comics, and novels, manage favourites and reading history, download content for offline reading where supported, and open compatible local files. The project is built around the principle of Stability, Speed, and Smoothness.

Hybrid reading

Read supported manga, comic, and novel sources and use local reading workflows in one Android application.

Library and offline use

Organize favourites and reading progress, and use downloads or local files where those features are supported.

Open source

Miyorare is developed publicly on GitHub, where users can inspect source code, releases, issues, and project discussions.

Optional Google Drive sync

Miyorare can optionally use Google Sign-In and Google Drive to synchronize Miyorare-related app data and files. This feature is only activated when a user chooses to sign in and grants the requested permissions. Miyorare requests drive.appdata for its application-specific Drive data and drive.file for files created or selected for use with Miyorare. Google user data is not used for advertising.

You can use Miyorare without enabling Google Drive sync. For details about how Google user data is accessed, used, stored, and shared, read the Miyorare Privacy Policy.
