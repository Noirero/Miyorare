Privacy Policy

This Privacy Policy explains how Miyorare handles information when you use the Miyorare Android application and this official website.

1. General approach

Miyorare is an open-source reader. The project is designed primarily around on-device operation. Some optional features connect to third-party services only when you choose to use them.

2. Google authentication and Google Drive

When you choose to use Google Drive sync, Miyorare uses Google Sign-In to let you select a Google account and requests the permissions needed for that feature.

  • email — used by Google Sign-In for the selected account.
  • https://www.googleapis.com/auth/drive.appdata — used for application-specific data in Google Drive.
  • https://www.googleapis.com/auth/drive.file — used for files created or selected for use with Miyorare.

Miyorare uses these permissions only to provide the Google Drive sync functionality you initiate. OAuth access tokens are obtained through Google services as needed; Miyorare's sync settings do not store OAuth tokens in the app's own preference storage.

3. How Google user data is used

Google user data accessed through the permissions above is used to authenticate the selected account and to read, create, update, or synchronize Miyorare-related data in Google Drive as required by the sync feature. Miyorare does not use Google user data for advertising.

4. Sharing and transfer

Miyorare does not sell Google user data. Data used by the Google Drive integration is exchanged with Google services to perform the requested sync operation. Third-party source websites, tracking services, or other integrations that you separately choose to use are governed by their own privacy practices.

5. Local data

Reading history, favourites, settings, downloads, local-library information, and other app state may be stored on your device. If you enable an optional sync or backup feature, selected app data may also be stored in the destination you choose.

6. Retention and deletion

Miyorare does not operate a separate Miyorare cloud account that must be deleted. You can stop Google Drive access by signing out or disabling the integration in Miyorare and by removing Miyorare's access from your Google Account. You may also delete Miyorare-related files from Google Drive where applicable. Local app data can be removed using the app's controls or Android's application data controls.

7. Website

This website is a static project website hosted through GitHub Pages. GitHub may process technical request information as the hosting provider according to GitHub's own privacy practices.

8. Security

The project aims to request only the access needed for enabled features and to avoid unnecessary handling of credentials. No method of electronic storage or transmission can be guaranteed to be completely secure.

9. Changes

This policy may be updated as Miyorare changes. Material changes will be reflected on this page with an updated effective date.

10. Contact

For privacy questions, bug reports, or requests related to Miyorare, use the project's public GitHub repository and issue tracker at github.com/Noirero/Miyorare.

Google API Services User Data Policy: Miyorare's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
