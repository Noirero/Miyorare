Panduan Miyorare

Panduan ringkas untuk memakai fitur Miyorare Main saat ini. Miyorare adalah aplikasi Android open-source untuk membaca manga, komik, dan novel dari source yang kompatibel maupun file lokal.

Miyorare tidak menyediakan konten bawaan. Source, extension, plugin, dan website eksternal adalah integrasi terpisah.

1. Mulai menggunakan Miyorare

  1. Unduh APK Main terbaru dari GitHub Releases resmi Miyorare.
  2. Instal APK. Android mungkin meminta izin memasang aplikasi dari browser atau file manager karena Miyorare didistribusikan di luar Play Store.
  3. Saat pertama dibuka, selesaikan pengaturan awal dan pilih lokasi penyimpanan bila diminta.
  4. Tambahkan Source Pack, source, extension, atau gunakan koleksi file lokal.
  5. Buka Jelajah untuk mencari bacaan, atau Local untuk membaca file yang tersimpan di perangkat.
Catatan: halaman ini mengikuti Miyorare Main v1.4.4. Fitur pada Beta dapat berbeda dan berubah sebelum dipromosikan ke Main.

2. Memasang Miyorare Source Pack

Source Pack adalah paket source resmi Miyorare yang didistribusikan terpisah dari APK inti. Saat ini Miyorare menyediakan paket utama untuk bahasa Indonesia dan English.

  1. Buka Pengaturan → Sources/Extensions → Miyorare Source Packs.
  2. Pilih Miyorare-ID untuk source bahasa Indonesia atau Miyorare-EN untuk source berbahasa Inggris.
  3. Tekan Pasang atau Update jika pembaruan tersedia.
  4. Setelah terpasang, aktifkan source yang ingin digunakan.
  5. Atur visibilitas source agar hanya source yang diperlukan yang muncul di Jelajah dan pencarian.

Miyorare juga memiliki lapisan kompatibilitas untuk beberapa ekosistem source/extension pihak ketiga. Tingkat kompatibilitas dapat berbeda menurut source, website, plugin, dan versinya.

3. Jelajah dan pencarian

Jelajah adalah tempat utama untuk membuka source dan menemukan judul. Source yang terlihat di sini mengikuti source yang sudah dipasang dan diaktifkan.

  1. Buka tab Jelajah.
  2. Pilih source yang ingin digunakan, lalu telusuri daftar yang tersedia.
  3. Gunakan pencarian untuk mencari judul.
  4. Gunakan filter yang tersedia pada source atau pencarian, seperti bahasa dan opsi hasil, bila didukung.
  5. Jika terlalu banyak source tampil, nonaktifkan visibilitas source yang tidak digunakan melalui pengaturan source.

Hasil dan filter tertentu bergantung pada kemampuan source masing-masing. Jika sebuah source berubah atau sedang bermasalah, source lain tetap dapat digunakan secara terpisah.

4. Halaman detail judul

Setelah memilih manga, komik, atau novel, halaman detail menampilkan informasi judul dan daftar chapter yang tersedia dari source tersebut.

  • Buka chapter untuk mulai membaca.
  • Tambahkan judul ke Disukai agar mudah ditemukan kembali.
  • Gunakan kategori untuk mengelompokkan koleksi.
  • Progress membaca, bookmark, catatan, status koleksi, dan riwayat dapat membantu melanjutkan bacaan dari posisi terakhir.
  • Jika source mendukungnya, chapter dapat diunduh untuk dibaca offline.

5. Reader manga dan komik

Reader digunakan untuk membaca halaman manga/komik dan melanjutkan antar-chapter. Pengaturan reader dapat disesuaikan dari menu reader sesuai preferensi membaca.

  • Gunakan navigasi reader untuk berpindah halaman dan chapter.
  • Bookmark dapat digunakan untuk menandai bagian yang ingin ditemukan kembali.
  • Progress bacaan disimpan agar judul dapat dilanjutkan dari posisi terakhir.
  • Konten yang sudah didownload dapat dibaca tanpa perlu mengambil halaman lagi dari source selama file masih tersedia.

6. Reader Novel dan EPUB

Miyorare Main v1.4.4 menyediakan reader novel/EPUB dengan kontrol tampilan yang lebih lengkap.

  • Atur font, ukuran teks, weight, line height, paragraph spacing, margin, dan alignment.
  • Pilih preset tampilan Light, Sepia, Dark, atau OLED.
  • Progress EPUB disimpan dengan posisi yang lebih presisi agar melanjutkan bacaan lebih dekat ke paragraf atau offset terakhir.
  • Tool terjemahan dapat digunakan pada teks pilihan, paragraf, atau chapter penuh. Teks asli dan layout chapter tetap dipertahankan.

Ketersediaan tindakan tertentu dapat bergantung pada tipe dokumen dan konten yang sedang dibaca.

7. Disukai

Disukai adalah pustaka utama untuk judul yang ingin disimpan. Tampilan Main saat ini mendukung pemisahan Manga/Novel, kategori, quick filter, dan pengelolaan koleksi.

  1. Tambahkan judul dari halaman detail ke Disukai.
  2. Buat atau pilih kategori untuk mengelompokkan judul.
  3. Gunakan switch Manga/Novel serta filter yang tersedia untuk mempersempit koleksi.
  4. Buka kembali judul untuk melanjutkan chapter dan progress terakhir.

Untuk pustaka besar, Miyorare memiliki mode pemuatan bertahap yang dirancang agar penggunaan RAM dan pemuatan cover tetap lebih terkontrol.

8. Disukai Private

Disukai Private adalah workspace koleksi terpisah untuk judul yang ingin dikelola lebih privat.

  • Buka Disukai → Private untuk masuk ke workspace Private.
  • Judul dapat dipindahkan dari koleksi Normal ke Private.
  • Kategori Private dikelola terpisah dari kategori Normal.
  • Memindahkan judul ke Private tidak menggandakan file download yang sudah ada; Normal dan Private dapat merujuk file download yang sama.
  • Pengaturan tema, perlindungan, backup, dan privasi Private tersedia pada bagian pengaturan yang terkait.

Ketika isolation aktif, workspace Private tetap terpisah. Gunakan fitur ini bersama pengaturan keamanan perangkat dan aplikasi sesuai kebutuhan.

9. Download dan baca offline

Chapter dari source yang mendukung download dapat disimpan agar dapat dibaca offline.

  1. Pilih chapter yang ingin diunduh dari halaman detail.
  2. Buka bagian download untuk melihat item yang sedang mengantre atau tersimpan.
  3. Atur folder download melalui pengaturan penyimpanan bila diperlukan.
  4. Setelah selesai, buka chapter dari Miyorare untuk membaca file yang sudah tersimpan.

Download tetap bergantung pada source. Jika website sumber berubah, login kedaluwarsa, atau akses gambar ditolak, proses download dari source tersebut juga dapat terpengaruh.

10. Local dan file di perangkat

Miyorare dapat digunakan sebagai reader untuk koleksi lokal. Format yang didukung mencakup CBZ, ZIP, EPUB, dan PDF.

  1. Buka bagian Local.
  2. Pilih atau izinkan lokasi penyimpanan yang berisi koleksi Anda.
  3. Lakukan scan/rescan bila file baru belum terlihat.
  4. Pilih judul atau file untuk membacanya dengan reader yang sesuai.

Jika file tidak terdeteksi, periksa ekstensi file, izin folder, lokasi penyimpanan, dan pastikan file tidak rusak.

11. Riwayat dan melanjutkan bacaan

Riwayat membantu menemukan kembali bacaan yang baru dibuka. Progress disimpan agar Anda dapat melanjutkan dari posisi terakhir yang tercatat.

Riwayat berbeda dari Disukai: sebuah judul dapat tercatat sebagai pernah dibaca tanpa harus dimasukkan ke koleksi Disukai.

12. Reader Journey

Reader Journey mencatat perjalanan membaca jangka panjang menggunakan aktivitas membaca yang memenuhi syarat.

  • Lifetime XP, level/rank, achievement, Reader Profile, Reader Title, dan showcase achievement.
  • XP berbasis penyelesaian yang terverifikasi, bukan sekadar membuka item.
  • Aktivitas saat Incognito/Peek aktif dikecualikan dari Journey.
  • Import atau mark as read tidak memberi XP retroaktif.
  • Reread dapat memberi reward kecil dengan pembatasan agar tidak mudah dieksploitasi.
  • Kosmetik dan celebration milestone bersifat tambahan dan tidak mengunci fitur inti membaca.

Year in Review

Year in Review menampilkan ringkasan statistik agregat. Jalur share dirancang tanpa membawa identitas manga/source ke hasil yang dibagikan.

13. Backup dan restore

Gunakan Pengaturan → Backup & Restore untuk membuat cadangan data dan memulihkannya kembali.

  • Backup membantu memindahkan atau menjaga data koleksi dan progress yang kompatibel.
  • Restore dari backup Mihon yang kompatibel dapat diarahkan ke Disukai Normal atau Disukai Private.
  • Urutan kategori, progress membaca, riwayat, dan bookmark yang kompatibel dipertahankan sejauh tersedia dalam data backup.
Saran: simpan file backup di lokasi yang aman sebelum mengganti perangkat, menghapus data aplikasi, atau melakukan perubahan besar pada penyimpanan.

14. Google Drive Sync

Google Drive Sync bersifat opsional. Miyorare tetap dapat digunakan untuk membaca tanpa login Google.

  1. Buka Pengaturan → Google Drive Sync.
  2. Login dengan akun Google ketika Anda memang ingin menggunakan sinkronisasi.
  3. Berikan izin yang diminta untuk data aplikasi Miyorare.
  4. Gunakan sinkronisasi untuk menyelaraskan data Miyorare yang didukung antarperangkat.

Data sinkronisasi aplikasi disimpan melalui area data aplikasi Google Drive. Miyorare tidak menggunakan data Google untuk iklan. Penjelasan akses dan penggunaan data tersedia di Privacy Policy.

15. Tampilan, privasi, dan keamanan

Pengaturan Miyorare dikelompokkan agar tampilan, reader, source, download, privasi, dan layanan dapat diatur tanpa mencampur fungsi utama.

  • Miyorare Modern menyediakan sistem visual Miyorare yang lebih baru pada Disukai, Jelajah, Download, Pengaturan, dan bagian lain.
  • Mode terang dan gelap tersedia sesuai pengaturan tampilan.
  • Bagian Privasi & keamanan mencakup perlindungan aplikasi, kebijakan screenshot, dan pengaturan terkait Disukai Private.
  • Pengaturan source dan extension berada pada bagian Sources/Extensions.

16. Mengatasi masalah umum

Source tidak muncul

Pastikan Source Pack/extension sudah terpasang, source diaktifkan, dan visibilitasnya di Jelajah tidak dimatikan.

Source terbuka tetapi hasil atau gambar gagal dimuat

Coba source lain untuk memastikan masalah tidak hanya berasal dari website tersebut. Website sumber dapat mengubah API, proteksi, cookie, atau aturan jaringan tanpa perubahan pada aplikasi Miyorare.

Source membutuhkan login

Buka alur login/WebView yang tersedia untuk source tersebut dan selesaikan login. Jika sesi kedaluwarsa, login ulang mungkin diperlukan.

Download gagal

Periksa koneksi, ruang penyimpanan, izin folder, status login source, dan apakah chapter masih dapat dibuka secara online.

File Local tidak terlihat

Periksa izin lokasi penyimpanan, lakukan rescan, dan pastikan file menggunakan format yang didukung serta tidak rusak.

Google Drive Sync meminta login lagi

Buka kembali pengaturan Google Drive Sync dan lakukan otorisasi ulang jika akses Google sudah kedaluwarsa atau dicabut.

Masalah tetap terjadi

Laporkan melalui GitHub Issues. Sertakan versi Miyorare, nama source bila relevan, langkah untuk memunculkan masalah, serta screenshot atau rekaman layar jika aman untuk dibagikan.

Masih bingung?

Mulai dari tiga langkah paling dasar: instal Main terbaru, pasang Miyorare-ID atau Miyorare-EN, lalu buka Jelajah. Fitur lain dapat diatur setelah alur membaca dasar sudah berjalan.
